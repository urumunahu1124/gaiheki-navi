# 外壁塗装ナビ（仮）— gaiheki-navi

外壁塗装・屋根塗装の費用と自治体助成金を、自治体公式情報に基づいて整理する静的サイトのプロトタイプ。
**未公開**。GitHubリポジトリ名は `gaiheki-navi` で確定（2026-11-26、ユーザーがPrivateで作成予定）。それまでの仮置き場所がこのフォルダ。

## 構成

- `build.py` — 静的ジェネレータ（Python標準ライブラリのみ）
- `data/subsidies.csv` — 初期データ20自治体（元: `~/workspace/seo-site-exterior-painting/subsidies-initial.csv`、全件公式ページ確認済み・2026-11-25確認）
- `data/chiyoda-2026.json` — 千代田区の今年度版（令和8年度）公式再確認結果（2026-11-26、公式ページ更新日2026-11-16）でCSV行を上書きするファイル。令和8年度は面積単価2,000円/㎡の記載が無くなり対象経費50%・上限50万円のみ、かつ予算到達で既に受付終了
- 生成物: `index.html`（トップ）、`subsidies/index.html`（DB一覧）、`subsidies/<slug>/index.html`（自治体ページ×20）、`alternatives/`（助成金なし自治体の代替策）、`about/`（出典方針）、`assets/style.css`

## 再生成

```bash
python3 build.py
```

- 全国DBは作らない（ヌリカエが1,718自治体のDBを保有）。地域を絞った深掘り＋「助成金なし」自治体の代替案内が核
- 数字は公式ページで確認できたものだけ。費用相場の具体額は出典未確認のため未掲載
- 提携申請・送客リンク設置はサイトが形になってから。現在はプレースホルダ表示のみ
